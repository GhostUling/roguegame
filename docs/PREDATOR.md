# 捕食者 PREDATOR —— 新模式设计稿

> 状态：**P0（骨架）已落地**：模式表与旋钮、七形态、猎物 AI、同族士兵、即时复活槽、5:00 胜负、每 30 秒一条的猎物强化、HUD/结算/渲染。**未落地**：怪物强化池 25 张、形态数值调平、图鉴分节。每落地一块更新本行，偏差写进 §14。
>
> 定位：把「被割的草」翻过来。你不再是那台自动开火的机体，你是怪潮里的一只；屏幕上那台机才是猎物。死亡不是失败，是换一只怪继续咬。
>
> 命名待定：建议 `predator` / 捕食者 / `PREDATOR`；备选 `reverse` / 逆流、`hive_mind` / 蜂主。

## 0. 一句话

**五分钟猎杀你自己熟悉的那台机。** 你操控一只怪，士兵越聚越多，主角越打越强；死了立刻在三只候选怪里挑一只接着咬，一路把它啃到阶段三，看谁先撑不住。

## 1. 设计目标

1. **反转要有说服力**：主角必须由现有引擎驱动（自动索敌 + 自动开火 + 主动技），玩起来就是平时那个它，只是不再受你控制。
2. **死亡是节奏，不是惩罚**：右上角预先绑定 3 个复活槽，死了立刻随机换其中一只（不重复刚死的），强化一律保留。
3. **三种形态各司其职**：近战靠接触、远程靠弹道、首领靠弹幕——每只怪的打法必须看得出区别，否则就是一套手感换皮。
4. **不污染现有三条路径**：标准 / 双子 / 溢流的任何数值与代码路径默认不变；阵营翻转必须靠模式开关生效（`docs/CONTRIBUTING.md` 的兼容性约束）。

## 2. 玩法循环

```
开局挑一只怪（默认追击者） + 挑一台机体当猎物
  → 带士兵冲向猎物，普攻自动，大招键手动
  → 被打死 → 立刻从绑定的复活槽随机换怪（当前已解锁的种类）+ 0.8s 无敌重生
  → 造成伤害攒经验 → 升级抽「怪物强化」（25 张新池）
  → 猎物按节拍变强（每 30s 一条强化，阶段：常态 → 背水）
  → 5:00 内击杀 = 通关；时间到 = 失败
```

## 3. 与现有模式的结构差异

### 3.1 模式表一行（`game/core/modes.ts`）

```ts
predator: {
  id: 'predator', name: '捕食者', tag: 'PREDATOR', accent: 'rose',   // 新强调色
  pilotSlots: 1,        // 这里选的是"猎物"，不是你的机体
  wingSpacing: 0,
  spawnMultiplier: 1,   // 沿用标准波次，士兵的规模靠 swarmMultiplier
  maxAlive: 260,        // 士兵上限（首版建议，靠手测调）
  growthScale: 1,
  threatScale: 0,       // 士兵不需要越打越痛，是你自己在变强
  pooledHp: false,
  cardPool: 'monster',  // 第三张卡表
  manualSpawn: false,   // 士兵自动补充
  devOnly: false,
  // 新旋钮（§3.2）
}
```

### 3.2 需要新增的模式旋钮（都是数据，不散写）

| 旋钮 | 含义 | 首版建议 |
|---|---|---|
| `swarmMultiplier` | 每波补充士兵数量倍率（你的军队规模） | 1.5 |
| `heroHpScale` | 猎物血量 = 机体 HP × 该系数 | 12 |
| `contactDamageScale` | 玩家形态的接触伤害倍率 | 2.5 |
| `pilotSpeedScale` | 形态移速换算（§4.1） | 2.4 |
| `runDurationSec` | 猎杀时限 | 300 |

`runDurationSec` 与溢流欠着的五分钟骨架只是同名概念：**本模式自己实现，不去改溢流**（那边还欠着，两码事）。

### 3.3 场上实体各自是谁

| 实体 | 用什么类型 | 谁驱动 | 打谁 |
|---|---|---|---|
| 你（怪形态） | 复用 `player`，但 HP/半径/外观/攻击来自怪物表 | 摇杆 / WASD + 大招键 | 猎物 |
| 猎物（原本的主角） | 新 `hero: Player`（沿用 Player 的武器与强化字段） | AI 脚本（§5） | 你 + 士兵 |
| 同族士兵 | 新 `swarm: Enemy[]`，与 `enemies` 同类型 | 沿用 `stepEnemyAi`，目标换成猎物 | 咬猎物，也会被猎物割 |
| 原有的 `enemies` | 本模式不启用 | — | — |

把士兵另开一个数组而不是复用 `enemies`，理由是：`enemies` 绑死了掉落、经验、`killEnemy` 的卡牌钩子和玩家子弹的命中目标。复用它会立刻引发「你打死自己的士兵还升级」，是本项目最忌讳的语义混乱。

### 3.4 阵营：碰撞矩阵的最小改法

- `engine/collision.ts` 已经是纯几何（`circlesTouch` / `roundHitsEnemy` / `firstWingHit`），不改几何，改的是**遍历谁**。
- 新增一个纯函数解析「当前模式的猎物列表」：
  ```ts
  // engine/targets.ts（纯函数，有单测）
  export function preyOf(engine): EnemyLike[]   // 标准/溢流 = engine.enemies；捕食者 = [engine.hero]
  export function isPreyHostile(mode): boolean  // 玩家子弹是否与 enemies 碰撞
  ```
- 玩家弹道与一切玩家来源的伤害，目标从硬编码 `this.enemies` 改成 `preyOf()`；标准/溢流返回 `enemies`，**行为逐字节不变**。
- 猎物的攻击走现成的「敌方通道」：它的弹幕进 `enemyProjectiles`（命中你），它的机体接触走现在的 melee 判定（命中你和你的士兵）。
- 士兵的接触伤害复用 `allies` 的做法（`ALLY_CONTACT_COOLDOWN` 那种逐单位冷却 + `DamageSource = 'ally'`），保证「士兵击杀不计入你的击杀触发卡」——这是 `DamageSource` 规则的直接延伸。
- **标记约定要翻一次**：`render/friendlyMarker.ts` 的翡翠环是给「玩家单位」的，260 只士兵不可能每只画环。本模式改成给**猎物**画一圈红色锁定环（新 `render/preyMarker.ts`，与 friendlyMarker 同级、同样只有一处定义），士兵不带标记。这条例外必须写进 `docs/CONTRIBUTING.md`，否则下一个改动会当成违规。

## 4. 玩家侧：怪物形态

### 4.1 数值来源（`game/core/predatorForms.ts`，纯数据 + 纯函数）

直接读 `core/enemyTypes.ts` 的 `ENEMY_TYPES`，只做三件换算，别处不写第二份：

```ts
pilotHpFor(type, elapsed)      // 该怪 HP（含成长曲线）× PILOT_HP_SCALE（当前 1：与同族士兵一致）
pilotSpeedFor(type)            // clamp(base * pilotSpeedScale, 3.2, 6.0)
pilotContactFor(type, scale)   // round(base damage * contactDamageScale)
```

**血量就是士兵的血量**：`PILOT_HP_SCALE = 1`，你和一只同族在同一时刻一模一样脆。这是刻意的——「我也是士兵」是这个模式的身体感受，靠走位和换怪活着，不靠血条。追击者开局 40 HP，猎物两梭子就没了；重装者 120、星型统领 850 只能通过换怪摸到。

首版换算结果（4.4 是 α 的机体速度，用来对比）：

| 形态 | 接触伤害 | 移速换算 | 弹道/特有 |
|---|---:|---:|---|
| 追击者 | 12 → 30 | 2.0 → 4.8 | 无 |
| 疾行者 | 9 → 23 | 3.6 → 6.0(封顶) | 无 |
| 重装者 | 22 → 55 | 1.15 → 3.2(保底) | 无 |
| 狙击手 | 16 → 40 | 1.7 → 4.1 | 锁定线弹，弹速 11 |
| 冲锋角 | 20 → 50 | 2.0 → 4.8 | 锁定方向冲刺 3.8× |
| 裂殖母巢 | 15 → 38 | 1.35 → 3.3 | 死亡分裂 |
| 星型统领 | 32 → 80 | 1.35 → 3.3 | 16 发环形弹幕 |

### 4.2 普攻自动 + 大招键

- **普攻（自动）**：近战形态 = 接触伤害（沿用 0.45s 无敌帧的对称规则，猎物也按无敌帧结算）；狙击手 = 每 3.2s 自动朝猎物射一发非锁定弹；母巢 = 接触；首领 = 每 4.2s 自动一轮 8 发半环。
- **大招键（SPACE / HUD 按钮，沿用 `triggerActiveSkill` 入口）**：

| 形态 | 大招 | 冷却 | 说明 |
|---|---|---:|---|
| 追击者 | 扑咬突进 180px | 4s | 路径上第一个目标受 1.6× 接触伤害 |
| 疾行者 | 相位穿影 | 3s | 0.25s 内无视碰撞穿过猎物 |
| 重装者 | 震地 | 6s | 120px 击退 + 0.4s 僵停（复用 `Enemy.stunTimer`） |
| 狙击手 | 蓄力锁线 | 5s | 0.7s 跟踪 + 0.5s 锁定（`enemyAi.ts` 的同一套时间轴），伤害 2.4× |
| 冲锋角 | 三段冲锋 | 6s | 锁定方向，3.8×，命中不中断（`chain_charge` 卡再加段） |
| 裂殖母巢 | 裂解 | 8s | 原地生 3 只士兵（继承当前波次小怪属性） |
| 星型统领 | 十六环 | 7s | 16 发完整环形弹幕，弹速 5.5、单发 18（与 AI 版一致） |

`boss` 只在 t ≥ 180s 后才进入可绑定名单（`BOSS_FORM_AFTER`），之后一直在。

### 4.3 复活槽：死亡不是弹窗

- **右上角 3 个槽位，开局就能全部绑定**（`components/RespawnSlots.tsx`）。名单是当前时刻已解锁的怪种（45s 前只有追击者/疾行者，90s 解锁狙击手，150s 解锁母巢，180s 解锁首领形态）。
- **死亡立刻自动复活**，从已绑定的槽里随机取一个，**绝不重复刚死的那个**；只绑了一个槽时就一直是它。一个都没绑则随机取当前已解锁名单（排除刚死的）。
- 重生位置：猎物 300px 半径随机方向（不找安全边缘，节奏要快），0.8s 无敌。绑定不是消耗，槽位一直在。
- 因为不再有选形态的弹窗，**整个世界不会因你死亡而暂停**——士兵继续咬、猎物继续开火。这是「你也是士兵」最直接的那一层。
- **强化全部保留**，但按形态过滤：卡面必须写明适用形态（`全局 / 近战 / 远程 / 首领`），不适用时卡置灰、不消耗（他的规则：不存在「装了没效果」）。
- 死亡次数不封顶，但每次死亡触发 `ramp_moon` 这类「用失败换成长」的卡（§7）。

## 5. 敌侧：脚本操控的猎物

### 5.1 AI 脚本（`engine/preyAi.ts`，纯决策 + 引擎落副作用，照 `enemyAi.ts` 的样子写）

**它不知道你是谁。** 猎物只读一个东西：**离它最近的那具敌对机体**——一名士兵或你，谁近算谁（`engine/index.ts` 的 `nearestHostile()`），外加「有多少机体压在它身上」（`PRESSURE_RADIUS` 内计数）。视图里**没有任何 pilot 专属字段**，所以它不可能优先锁定玩家：远远跟着就完全不被注意，贴上去咬就是把自己变成最近的目标，也就会挨那一梭子。主炮的索敌也用同一个 senses。

走位策略（按优先级，**生存为第一指南**）：
1. **脱离接触**：最近机体 <150px，或 `PRESSURE_RADIUS`(220px) 内压着 ≥4 具 → 反方向拉开，并且偏离开兵潮质心（逃跑不能跑进场子）；
2. **重伤优先**：血量 < 50% 时脱离半径放大到 320px，并且**永不主动逼近**；
3. **不换角落**：离边缘 <90px 时先往场内走（被堵在角上等于死）；
4. **保持战线**：健康、且 460px 内一具机体都没有时，才缓慢逼近（否则它会一路逃到底，游戏无法结束）；
5. **绕环**：以上都不紧迫时，既不冲也不逃，绕着最近机体走环——侧移分量每 1.4s 换一次向，重伤时减半。

**大招是逃生键，不是输出键**：只在「≥8 具机体压在 220px 内」或「重伤且被贴身」时才放，用来解围；不再因为「你在 240px 内」而顺手砸你脸上。

刻意保留的弱点：它不会绕到你背后、不会躲你的大招、也不会集火你——留给玩家的操作空间就是「什么时候暴露自己」。

### 5.2 阶段与节拍（这是难度曲线，不是数值堆叠）

| 来源 | 触发 | 变化 |
|---|---|---|
| 常态 | 0:00 | 一台机，血量 = 机体 HP × `heroHpScale`，跑完整 AI |
| 背水 | 血量 < 35% | 射速 ×0.6、主动技冷却减半、脱战自愈关闭；屏幕边缘出现红色警示环 |
| 强化 | **每 30 秒白拿一级**（`engine/preyBuff.ts`） | 直接抽**本模式卡池（= 标准池 25 张）**里还没满级的卡，走和玩家升级完全同一条 `apply(player, level)` 路径。猎物就是 `player` 实体，所以它的强化列表与你的构筑是同一张表的两侧 |

- 抽卡时**只有两张被排除**：`magnet` 与 `gravity_siphon`（`PREY_EXCLUDED_KEYS`）。它们只跟晶石与升级有关，而猎物不拾取晶石、也永远不升级——发给它就是一张「装了没效果」的卡，违反卡池规则。其余 23 张全部可发，满级的卡自动跳出候选。
- 一局 10 次节拍远不到 23 张 ×3 级的上限，所以基本不会重样。本模式里士兵死亡不给猎物经验、也不触发升级弹窗，所以**这条节拍是猎物唯一的成长来源**。
- 因为牌桌就是那张表，猎物的强化天然是**整套系统**而不是一串系数：它可能拿到「终决处刑」直接处决残血士兵、拿到棱镜炮台/镜像分身/射击回响来压制你的兵潮、拿到纳米坚盾挡下你的一口。
- 每次拿卡在猎物头顶飘紫字「卡名 Lv.N」，HUD 第二行常驻「猎物拿走 · 最新那张 + Lv」+「下一条 Xs」，暂停面板第 3 页「猎物强化记录」按时间列出（时间 / 卡名 / 等级 / 该卡自己的效果文案），第 1 页的强化列表就是它当前的全部构筑。**玩家必须能看清对面变成了什么**，否则随机强化只是不公平而不是有压力。

**不出现双子**：按拍板意见，猎物永远是一台机，只在标准模式的机体语义上调强度，不引入第二条机位。

## 6. 同族士兵：与你同种的怪潮

- 波次沿用 `SPAWN_BRACKETS` 与 `pickEnemyType`，所以「种类越来越多」是现成行为；数量乘 `swarmMultiplier`。
- 士兵有逐单位接触冷却（`swarmContact` 进 `engine/swarm.ts` 纯模块），否则 260 只叠在一起会把猎物瞬间融化。
- 士兵死亡**不给你经验**（经验只来自你对猎物造成的伤害），避免「原地让士兵自杀刷级」。
- 它们不是宠物，是同族：会真的对猎物造成接触与弹幕伤害，也会被猎物反杀（张力见下条）。
- 代价与张力：猎物会成排割掉你的士兵，所以 5 分钟里兵力是消耗品，而猎物几乎不回血。

## 7. 怪物强化卡池（25 张，`game/cards/monsterUpgrades.ts`）

规范（沿用 `docs/CONTRIBUTING.md` 的卡池规范，加三条本模式专属）：

- key 与两个池全局唯一（已核对，50 个现有 key 无一冲突）；共用一个 `upgradeLevels`。
- 每张必须有实际效果，禁止 0 伤害纯特效卡。
- 不做纯增伤堆叠；「大量子弹但单发伤害不高」优先。
- 每张标注**适用形态**，UI 置灰不适用的。
- 任何「替换普攻形态」的卡，必须在 260 只部的画面里验证过才允许落地（轨道囚笼的教训）。

## 8. 时间、胜负与结算

- **时限**：`runDurationSec = 300`。5:00 到且猎物存活 = 失败；击杀 = 通关。
- **死亡**：不判负，只换怪。所以本模式**不使用** `deathPenalty`（溢流的「死亡只扣时间」在这里语义不同，不要硬套同一个实现）。
- 结算新增：猎杀用时（或剩余时间）、对猎物总伤害、峰值士兵数、换怪次数、每种形态的使用时长。
- 高分沿用现有 `localStorage` 结构，但**不与标准/双子/溢流通榜**（模式表已有分池语义，排行榜若混算会让这个模式靠刷时长占榜）。

## 9. HUD 与表现层

1. 顶部第一行是**猎物血条**（居中，红→紫渐变，带阶段徽章「常态 / 背水」）。

## 13. 已定（2026-10-23 拍板）

1. **士兵同族、真结算**：场上怪潮不是宠物，是与你同族的士兵，会真的打猎物，也会被猎物打死。
2. **猎物 AI 必须聪明**：胜负手是「我用操作和选怪思路赢它」，脚本不能是沙包；§5.1 的走位与技能策略在 P0 就要立起来。
3. **换怪无代价**：死亡次数不封顶，一局死很多遍是预期体验。
4. **失败条件只有一个**：时限到还没击杀猎物 = 失败。不做「兵力清空」溃败判定。
5. **不出现双子**：按标准模式的机体语义改强度，不引入第二条机位。
6. **风险换爽那 4 张原样保留**：捕食者是另一套语义，HP=1 配换怪无敌是笑点不是自杀。
7. **时限本模式自己实现**，不动溢流欠着的五分钟骨架。
8. **自己的血量与同族士兵一致**（`PILOT_HP_SCALE = 1`），并且必须用**血条**显示，不是一串小字。
9. **每次死亡弹三选一太麻烦** → 右上角绑定 3 个复活槽，**开局 3 槽就全部可选**；死亡立刻随机从已绑定槽里复活、**不重复刚死的那个**。
10. **对面必须越来越强**：每 30 秒让猎物从**现成的卡池**里白拿一级（不是新造一批强化），并且必须能在暂停里查得到——否则玩家无法应对，随机就只是不公。

## 14. 与设计稿的偏差（实现时填）

> 实现过程中每一条与本节不一致的，写在这里，别改上面的目标描述。

**P0 已发生的偏差**

- **架构换成更省的一版**：没有新建 `hero` 字段。引擎的 `player` 直接就是被脚本操控的猎物，`enemies` 就是同族士兵，你是一个新实体 `pilot`（`core/predatorForms.ts` 定义形态）。好处是猎物的索敌、自动开火、机体被动、主动技全部原样复用；代价是阵营分支集中在引擎里，靠 `heroPrey` 一个开关控制。
- **`PILOT_HP_SCALE` 最终是 1，不是 §4.1 原本建议的 3**：探针先按 3（重装者 120 只站 0.8 秒）再按 12（追击者 480，一来一回）试过，2026-10-23 定案回到 1——「我自己也是个士兵」是玩家要的感觉，血量与同族完全一致，脆就用换怪补。换怪无冷却代价，所以这条不破坏节奏。
- **重装者的大招只做了伤害 + 击退**，没有 0.4s 僵停；P0 里猎物没有可复用的僵停字段。
- **P0 没有经验与升级**：士兵死亡不给猎物任何掉落与经验，所以 `cardPool` 暂时仍是 `standard`；怪物强化池落地时改 `monster`。
- **猎物 AI 已按「生存第一 + 不认识你」重写**（2026-10-23 第二轮，玩家要求）：初版把 `pilotX/pilotY` 直接喂给了策略，等于明告诉它你是谁、并且会主动朝你逼近。现在 `PreyView` 里没有任何 pilot 字段，只有「最近机体 + 220px 内机体数 + 自身血量比例 + 兵潮质心」，优先级也换成脱离接触 → 重伤逃跑 → 不换角落 → 保持战线 → 绕环。**代价**：它会逃，所以比初版更容易被兵潮咬死（探针：机器人正面冲，55 秒就结束了）。
- **猎物索敌 = 最近机体，不是优先你**：主炮从只扫 `enemies` 改成 `nearestHostile()`（士兵 ∪ 你，取更近的那个）。远端跟着它不会被瞄准，贴脸咬才会吃到枪口——这一条替代了原来「优先锁定玩家」的实现。
- **三选一弹窗已被换掉**（2026-10-23 第二轮拍板，见 §13.9）：`MorphModal.tsx` 与 `GameState` 的 `morph` 状态、`onMorph` 回调、`applyMorph()` 全部删除，复活由 `respawnPilot()` 在伤害结算的那一帧内完成。因此本模式**不再有「世界停住挑形态」的喘息窗口**——这既是玩家要的（不打断），也是这一模式变难的地方。
- **`morphCandidates()` 已被 `bindableForms()` + `pickRespawnForm()` 取代**，`BOSS_FORM_WEIGHT`（15% 概率进候选）随弹窗一起删掉；首领形态现在是 180s 后一直可绑定。
- **猎物强化不另造表**（2026-10-23，玩家直接推翻了我的第一版）：我原本新建了 `core/preyBuffs.ts` 九条专属数值，但猎物本来就是 `player` 实体、`cards/upgrades.ts` 的 `apply(player, level)` 就是给它的——重复一张表违反约束 3。现在只保留 `engine/preyBuff.ts` 里「节拍 + 从没满级卡池抽一张」这条纯规则，九条数值全部删除。副作用是猎物的强化会带出**整套系统**（处决、炮台、分身、坚盾、冻结），比一串系数更有戏，也更凶。
